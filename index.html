方块世界

一个网页版的「我的世界」体素沙盒

  • W A S D 前后左右移动，鼠标控制视角
  • 空格 跳跃；快速按两次切换飞行模式（Shift 下降）
  • 按住左键 挖方块（泥土快、石头慢，镐挖石头更快且有耐久，木镐 / 石镐 / 铁镐 / 红宝石镐逐级更强）/ 攻击动物
  • 斧头 木斧 / 石斧 / 铁斧 / 红宝石斧逐级更快砍原木、木板，也是近战重劈武器（伤害 5 / 6 / 7 / 8）；铁斧用铁锭在工作台摆斧形合成，红宝石斧用红宝石
  • 挖矿 地下深处生成煤矿与铁矿：煤矿任意镐可采，铁矿需要石镐才会掉落；铁锭可以在工作台合成更快的铁镐（3 铁锭横排 + 2 木棍）
  • 熔炉 工作台用 8 块圆石合成，右键打开：放矿石 + 柴火（木棍 / 木板 / 原木 / 煤）烧出铁锭和煤
  • 锄头 木锄 / 石锄 / 铁锄 / 红宝石锄四级（2 块材料 + 2 木棍摆锄形）：右键草方块或泥土锄成耕地种麦子；石锄更耐用，铁锄一次耕 3×3 一片、红宝石锄一次耕 5×5，石头和已有方块会自动跳过
  • 灌溉 耕地旁 4 格内（同层或高一格）有水会自动变成深褐色湿润耕地，小麦生长约快一倍；贴着湖泊池塘开田最省心。水源消失约 45 秒后湿润耕地会干涸，干涸前把水补回即可
  • 铁桶 3 块铁锭在工作台摆 V 形合成铁桶：手持空桶对水面或岩浆源头右键即可装桶（只能装源头，流动的岩浆装不起），再对空地右键倒出。水桶能把水运到远处浇地灌溉；岩浆桶倒出的岩浆会四处流动、碰到会受伤，水和岩浆接触还会凝成玄武岩
  • 火把 煤放在木棍上合成 4 支火把，插在地上会照亮周围，夜晚挖矿必备
  • 鼠标右键 放方块 / 使用工作台、熔炉；拿生肉喂猪和狗可驯服，拿麦子喂牛和羊可繁殖
  • 驯狗 喂肉驯服，空手右键让它坐下/跟随，它会帮你打怪、护主
  • 养殖 牛和羊吃麦子不吃肉：锄地种麦收获麦子后，拿麦子分别喂两只成年同类（身上冒红心），它们会走到一起生下小幼崽；幼崽约 3 分钟长大，喂麦子可以催长，幼崽不会掉落物品
  • 熊猫 珍稀的黑白熊猫只隐居在竹林深处：每片竹林只有几分运气能遇到，碰上了也往往只有一两只。平时温顺不主动攻击人，但挨打后会皱起眉头怒冲过来咬你（跑远或等它气消就安全了，小熊猫只会吓跑）；手持竹子（或竹笋）能把它吸引过来，拿竹子分别喂两只成年熊猫，它们会走到一起生下小熊猫
  • 骑猪 用肉驯服猪后，空手对它右键骑上去，Shift 下来
  • 注意 猪羊挨打会逃，牛和野狗被打会反击，小心血量！
  • 1 ~ 9 或滚轮切换物品，Q 丢弃手上选中的物品（长按连续丢），E 背包，背包里抓起物品点面板外空白处可把整堆扔到地上，V 切换第一 / 第三人称视角，Esc 暂停
  • 装备 打羊掉羊毛，在工作台缝制帽子 / 衣服 / 裤子，穿上可减伤
  • 背包 打牛掉皮革，8 张皮革围一圈缝制皮革背包，放进装备栏「包」槽后多出 9 格储物空间
  • 昼夜 世界有白天与黑夜，还有晴 / 雨 / 暴雨天气；夜晚僵尸和蜘蛛会出没攻击你：蜘蛛贴地疾跑还会扑击，击败后掉落蜘蛛丝；天亮后露天僵尸被太阳烧灭，蜘蛛则转为中立游荡，出门前记得带好武器
  • Boss 火山顶盘踞着一条紫黑龙，靠近火山口就会惊醒它：它会俯冲撕咬、喷吐火球与烈焰，击败后可获得龙肉和龙皮
  • 手机 手机浏览器也能玩：左下摇杆移动，右侧拖动转视角，按钮负责跳跃 / 攻击 / 放方块 / 丢弃（丢）/ 背包，丢弃的物品会掉在脚前，走回去即可捡回
  • 视角 鼠标移动 / 手机右侧拖动转动视角；觉得太快或太慢，可在本菜单（手机点右上角 Ⅱ 暂停进入）拖动「视角灵敏度」滑杆，30% ~ 200% 即时生效并自动保存
  • 存档 每 20 秒自动保存到浏览器，也可在暂停菜单手动保存或导出存档文件备份
